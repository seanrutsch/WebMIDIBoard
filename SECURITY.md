# Security Policy

## Reporting a vulnerability

WebMIDIBoard is a browser application that communicates with local MIDI hardware through the Web MIDI API. We take all reports seriously and appreciate responsible disclosure.

To report a security issue, use GitHub's private vulnerability reporting: on this repository page, click **Code**, then **Report a vulnerability** (or file a draft security advisory). This keeps the issue private until it is resolved.

Please include:

- A description of the vulnerability and its potential impact.
- Steps or a proof of concept to reproduce it, where possible (browser, OS, and device setup help).
- Any mitigation you have identified.

Do **not** open a public issue or pull request for an unpatched security vulnerability.

## Supported versions

No releases have been published yet, so there are no supported versions at this time. Once the first release ships, this section will list which releases receive security fixes (expected: only the latest stable release).

## Response expectations

We aim to acknowledge new reports within 7 days and triage them within 30 days. This is a small project, so response times may occasionally be longer; we will keep you posted on the status of your report.
